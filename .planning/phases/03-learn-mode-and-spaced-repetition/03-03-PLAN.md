    **Create `src/screens/practice/PracticeSessionScreen.tsx`** (per D-08 through D-14, D-17):

    Active flashcard practice session. Uses the WordCard component (from Plan 02) for content display and GradeButtons for grading.

    **State management:**
    - `cards`: DueCard[] — loaded on mount via `getDueCards(db, today, 200)`. D-17 cap is enforced by the service.
    - `currentIndex`: number — tracks position in the queue.
    - `isRevealed`: boolean — whether back content is showing.
    - `isLoading`: boolean — initial load state.

    **On mount:**
    - Compute `today` using local date (same pattern as SM-2).
    - Call `getDueCards(db, today)`. If empty array returned, show "No cards due" message and a "Go Back" button.
    - If 200 cards returned, this is the daily cap (D-17). Show a note in the header.

    **Header (D-14):**
    - Use `navigation.setOptions` to set header title showing remaining count: `"{cards.length - currentIndex} cards left"`.
    - `headerStyle: { backgroundColor: colors.background }`, `headerTintColor: colors.text`.
    - Back button navigates back to Practice tab.

    **Flashcard front (D-08):**
    - When `isRevealed === false`: Render `<WordCard word={cards[currentIndex]} showFront={false} />` — this shows only the Arabic word, large and centered.
    - The ENTIRE screen is wrapped in a `Pressable` with `onPress={() => setIsRevealed(true)}` (D-09: tap anywhere to reveal).

    **Flashcard back (D-09, D-10):**
    - When `isRevealed === true`: Render `<WordCard word={cards[currentIndex]} showFront={true} />` — this shows all word fields including transliteration (if enabled), meaning, and example verse.
    - Use Reanimated `FadeIn` animation (or `withTiming` on opacity shared value) for a simple fade-in of the revealed content (D-09: no flip animation).
    - Below the WordCard, render `<GradeButtons intervals={previewGrades(currentSM2State)} onGrade={handleGrade} />`.
    - `currentSM2State` is derived from the current DueCard: `{ easeFactor: card.easeFactor, interval: card.interval, repetitions: card.repetitions, status: card.status }`.

    **Grading flow (D-13):**
    - `handleGrade(grade)`:
      1. Call `gradeCard(db, cards[currentIndex].id, currentSM2State, grade, today)` — this persists the SM-2 result to SQLite (PRAC-07).
      2. Set `isRevealed = false`.
      3. If `currentIndex < cards.length - 1`: advance to next card (`setCurrentIndex(i => i + 1)`).
      4. If last card: show session completion screen — "Practice complete!" with total cards reviewed count and a "Done" button that navigates back.
    - Do NOT remove graded cards from the array — just advance the index. This keeps the header count simple.

    **Daily cap message (D-17):**
    - If `cards.length === 200`, show a small banner at the top: "Daily limit reached (200 cards)" in `colors.textMuted`.

    **Session completion:**
    - After grading the last card, replace the card view with a centered completion message:
      - "Practice Complete" in `colors.text`, fontSize 24.
      - "{cards.length} cards reviewed" in `colors.textSecondary`.
      - "Done" button (same style as Start Practice) that calls `navigation.goBack()`.

    - Import from `'../screens/practice/PracticeSessionScreen'`.
    - Set `options={{ headerShown: true }}` on the PracticeSession screen.

    Background: `colors.background`. Use `StyleSheet.create()`.
