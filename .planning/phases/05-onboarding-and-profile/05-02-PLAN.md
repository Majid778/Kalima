### 2. `src/stores/streakStore.ts` — add one pure helper (exported)
```ts
export interface ActivityCell { date: string; count: number; intensity: 0 | 1 | 2 | 3; }
export function buildActivityGrid(
  activityDates: Record<string, number>,
  today: string,        // 'YYYY-MM-DD'
  weeks = 13,
): ActivityCell[][]      // weeks columns, each a 7-element array (Sun..Sat or chronological)
```
- Pure. Compute the date `weeks*7 - 1` days before `today` through `today` inclusive, in chronological order, grouped into columns of 7. Parse/step dates in UTC exactly like the existing date code in `progressService` (`new Date(`${date}T00:00:00Z`)`, `setUTCDate`). For each day: `count = activityDates[date] ?? 0`; `intensity = 0 if count===0, 1 if count===1, 2 if count===2, 3 if count>=3`. Do NOT use `Date.now()` — `today` is injected.
- Keep `computeStreak`/`computeLongest` untouched.
