# 05-01 — Onboarding (first-launch flow + level assessment)

**Subsystem:** store + screen + navigation gate (no SQLite)
**Requirements:** ONBD-01 (3-screen first-launch flow), ONBD-02 (Arabic level self-assessment adjusts initial experience)
**Depends on:** settingsStore (transliteration), mmkvStorage.

## Tasks

### 1. `src/stores/onboardingStore.ts`
Zustand + persist(mmkvStorage), `name: 'kalima-onboarding'`.
```ts
export type ArabicLevel = 'beginner' | 'alphabet' | 'reader';
interface OnboardingState {
  hasOnboarded: boolean;           // default false
  arabicLevel: ArabicLevel | null; // default null
  completeOnboarding: (level: ArabicLevel) => void;
  resetOnboarding: () => void;     // dev/testing helper
}
```
- `completeOnboarding(level)` — set `arabicLevel = level`, `hasOnboarded = true`, AND apply the initial default: `useSettingsStore.getState().setShowTransliteration(level !== 'reader')` (beginner/alphabet → true; reader → false). Import `useSettingsStore`.
- `resetOnboarding()` — `hasOnboarded = false`, `arabicLevel = null`.

### 2. `src/screens/onboarding/OnboardingScreen.tsx`
Single component, internal `step` state (0,1,2). Dark theme, full-screen, centered content, `colors`. No new pager dependency.
- **Step 0** — concept: title "Learn the Qur'an, word by word", body "Master the most frequent Qur'anic words first — the ~20% of vocabulary that covers most of the text." `Next` button.
- **Step 1** — concept: title "Watch your understanding grow", body "Every word you learn raises your '% of the Qur'an understood'. Practice daily to keep your streak." `Next` button. (A `Back` affordance to step 0 is fine.)
- **Step 2** — assessment: title "How's your Arabic?" with 3 large选项 buttons:
  - "Complete beginner" → `beginner`
  - "I know the alphabet" → `alphabet`
  - "I can read Arabic" → `reader`
  Tapping a choice calls `completeOnboarding(level)`.
- A small `Skip` text button (top-right or bottom) on every step → `completeOnboarding('beginner')`.
- Step indicator dots (3) at the bottom; active dot `colors.primary`, inactive `colors.surfaceLight`.
- Use `SafeAreaView` from `react-native-safe-area-context`.

### 3. Gate in `src/navigation/RootStackNavigator.tsx`
- Add `Onboarding: undefined` to `RootStackParamList`.
- Read `const hasOnboarded = useOnboardingStore((s) => s.hasOnboarded);`.
- When `!hasOnboarded`: render a stack with ONLY the `Onboarding` screen (so it is the full surface). When `hasOnboarded`: render the existing stack (Tabs + WordCard + PracticeSession + QuizSession + QuizResult) exactly as today. Because the store is reactive, `completeOnboarding` flips the tree to Tabs automatically.
- Keep `screenOptions={{ headerShown: false }}`; Onboarding screen has no header.

### 4. Unit test `src/stores/__tests__/onboardingStore.test.ts`
- Initial state: `hasOnboarded === false`, `arabicLevel === null`.
- `completeOnboarding('reader')` → `hasOnboarded === true`, `arabicLevel === 'reader'`, and `useSettingsStore.getState().showTransliteration === false`.
- `completeOnboarding('beginner')` → `showTransliteration === true`.
- `resetOnboarding()` restores defaults.
- Mirror `settingsStore.test.ts` / `streakStore.test.ts` setup (the MMKV mock is already configured in jest setup since those tests pass).
