# 04-01 — Progress & Streak Foundation

**Subsystem:** services + stores (no UI)
**Requirements:** PROG-01 (calc), PROG-02 (calc), PROG-05 (level state calc), PROG-06 (Today's Verse calc), STRK-01, STRK-02
**Depends on:** Phase 01 schema (words, word_verses, word_progress, levels, level_progress)

## Tasks

1. **`src/services/progressService.ts`** — read-only Drizzle queries + pure helpers:
   - `getQuranPercent(db): Promise<number>` — occurrence-weighted, status='review' (D4-03). Returns 0.0–1.0.
   - `getWordsLearnedCount(db): Promise<number>` — word_progress.status != 'new' (D4-04).
   - `getLevelsCompletedCount(db): Promise<number>` — level_progress.completed_at not null.
   - `getLevelProgressList(db): Promise<LevelProgressView[]>` — every level with `{ id, name, wordCount, cumulativeCoverage, unlocked, completed, bestQuizScore }` (D4-05 unlock rule applied).
   - `getTodaysVerse(db, today): Promise<{ verse, knownCount, totalCount } | null>` (D4-08).
   - `isLevelUnlocked(levelProgressRows, levelId): boolean` — pure helper, unit-tested.
   - `MILESTONES = [0.25,0.5,0.75,1.0]`; `crossedMilestone(prevPct, newPct): number | null` — pure, unit-tested.
2. **`src/stores/streakStore.ts`** — Zustand + persist(mmkvStorage), `name: 'kalima-streak'`:
   - state: `activityDates: Record<string, number>`, `currentStreak`, `longestStreak`, `lastActivityDate: string | null`, `celebratedMilestones: number[]`.
   - `recordActivity(today: string)` — increments `activityDates[today]`, recomputes `currentStreak`/`longestStreak`, sets `lastActivityDate`.
   - `markMilestoneCelebrated(m: number)`.
   - pure helpers exported for tests: `computeStreak(activityDates, today): number` (consecutive days ending today or yesterday — STRK-02 reset), `computeLongest(activityDates): number`.
3. **Unit tests** (`__tests__/`), mirroring `sm2.test.ts`:
   - `progressService.test.ts` — `isLevelUnlocked`, `crossedMilestone` (each threshold, no-cross, multi-cross returns highest newly-crossed).
   - `streakStore.test.ts` — `computeStreak` (today-only=1, consecutive run, gap resets, yesterday-still-counts-today-pending), `computeLongest`.
