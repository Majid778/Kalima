**Requirements:** PROG-01..07 (display), STRK-01/02 (display + record), QUIZ activity.
**Depends on:** 04-01 (progressService, streakStore), 04-02 (quiz screens).

## Decisions applied
- D4-08 Today's Verse; D4-09 milestone celebration fires once via `celebratedMilestones`; D4-10 centralized `recordActivity(today)` on every activity completion. D4-05: Learn tab **displays** lock/completion state but stays navigable (no hard gate in Learn).

## Tasks

### 1. `src/screens/JourneyScreen.tsx` — rewrite as the Home/hero screen
Mirror `PracticeHomeScreen` structure (`useFocusEffect` + `useCallback` reload, `import { db } from '../data/database'`, `getLocalToday()` from `services/sm2`, ActivityIndicator while loading). On focus, load in parallel:
- `getQuranPercent(db)` → headline. Render a large percent (e.g. `42.0%`) with a **horizontal progress bar** (track `colors.surfaceLight`, fill `colors.primary`, width = pct). No SVG/new deps — a bar is fine; do NOT add a charting library.
- `getWordsLearnedCount(db)`, `getLevelsCompletedCount(db)`, and `useStreakStore` `currentStreak` → a 3-stat row (Words learned / Levels done / 🔥 streak). Read streak via `useStreakStore((s) => s.currentStreak)`.
- `getPracticeStats(db, today).dueCount` → a "Continue" CTA card: if `dueCount > 0` show "Practice N due" → `navigation.navigate('PracticeSession')`; else show "All caught up" and a secondary "Learn" CTA → `navigation.navigate('Tabs', { screen: 'Learn' })` (or `navigation.getParent()?.navigate('Learn')`).
- `getTodaysVerse(db, today)` → "Today's Verse" card: render `verse.arabicText` via `<ArabicText>`, the `translation` below in `colors.textSecondary`, and a line "You know {knownCount}/{totalCount} words in this verse". Handle null (no verse) by hiding the card.

**Milestone celebration (D4-09):** after `getQuranPercent` loads, compute against the store's `celebratedMilestones`. For each `m` in `MILESTONES` where `pct >= m` and `!celebratedMilestones.includes(m)`: show a one-time `Modal` ("🎉 You understand {m*100}% of the Qur'an's words!") and call `markMilestoneCelebrated(m)`. If multiple uncelebrated thresholds are already crossed, celebrate the highest and mark all ≤ it as celebrated. Use a local state `celebrating: number | null` to drive the Modal; dismiss button closes it.

Header: set a screen title "Your Journey" (the tab already provides a header). Dark theme throughout; cards use `colors.surface`, radius 12, padding 16.

### 2. `src/screens/learn/LevelListScreen.tsx` — add lock/completion display
Replace the `getLevels(db)` load with `getLevelProgressList(db)` (returns `{ id, name, wordCount, cumulativeCoverage, unlocked, completed, bestQuizScore }`). For each row:
- If `completed` → show a ✓ (Ionicons `checkmark-circle`, `colors.success`) and `Best {Math.round(bestQuizScore*100)}%` if `bestQuizScore != null`.
- Else if `!unlocked` → show a lock (Ionicons `lock-closed`, `colors.textMuted`) and dim the row (`opacity: 0.6`).
- Keep the existing coverage % display and the existing `navigation.navigate('WordCard', { levelId, levelName })` for ALL rows (Learn is not hard-gated — display only). Use `useFocusEffect` so state refreshes after a quiz unlock.
Import `Ionicons` from `@expo/vector-icons` (already a dependency).

### 3. Activity wiring — call `recordActivity(getLocalToday())` on every completion
Use the non-reactive form `useStreakStore.getState().recordActivity(getLocalToday())` (import `useStreakStore` + `getLocalToday`). Add exactly one call at each completion point:
- **`src/screens/practice/PracticeSessionScreen.tsx`** — in `handleGrade`, in the branch that sets `setIsComplete(true)` (last card graded), call `recordActivity` once before/after setting complete.
- **`src/screens/quiz/QuizSessionScreen.tsx`** — right after grading + `recordQuizResult`, before `navigation.replace('QuizResult', ...)`.
- **`src/screens/learn/WordCardScreen.tsx`** — in `goToNext`, when advancing onto the **last** word (`currentIndex + 1 === words.length - 1` boundary, i.e. the user has reached the final card), call `recordActivity` once. Guard with a ref/state so it fires at most once per mount.
