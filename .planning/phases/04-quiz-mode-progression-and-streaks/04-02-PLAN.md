# 04-02 — Quiz Mode (service + UI + nav)

**Subsystem:** services + screens + navigation
**Requirements:** QUIZ-01..06, PROG-05 (unlock persistence), STRK (activity on quiz finish wired in 04-03)
**Depends on:** 04-01 (progressService unlock rule, streakStore), Phase 01 schema.

## Decisions applied
- D4-06 quiz = 20 questions, two types: `multiple-choice` ("What does ⟨arabic⟩ mean?", 4 options) and `matching` (match 4 arabic words to 4 meanings). Distractors = other words' meanings, prefer same level then global, never the correct answer, no duplicate options. Generation is PURE with injectable RNG seed → deterministic tests.
- D4-07 pass gate = 80% (`score/total >= 0.8`). Retakes free (QUIZ-05). Keep best score (`bestQuizScore = max(old,new)`).
- D4-05 passing a level unlocks the next: upsert `level_progress` for current level (`bestQuizScore`, `completedAt` when passed) AND upsert next level row `unlocked = 1`.

## Tasks

### 1. `src/services/quizService.ts` — pure gen/grade + DB persistence
Types:
```ts
export type QuizQuestion =
  | { kind: 'multiple-choice'; wordId: number; arabic: string; transliteration: string; correct: string; options: string[] }  // options shuffled, length 4, includes correct
  | { kind: 'matching'; pairs: { wordId: number; arabic: string; meaning: string }[]; meaningBank: string[] };               // 4 pairs; meaningBank = the 4 meanings shuffled
export interface QuizWord { id: number; arabic: string; transliteration: string; meaning: string; levelId: number; }
```
- `getQuizWords(db, levelId): Promise<{ levelWords: QuizWord[]; globalPool: QuizWord[] }>` — levelWords for this level; globalPool = a bounded sample of other-level words for distractors (cap ~200).
- `mulberry32(seed: number): () => number` — pure deterministic RNG (standard mulberry32). Internal helper, exported for tests.
- `shuffle<T>(arr, rng): T[]` — pure Fisher–Yates using rng. Exported for tests.
- `generateQuiz(levelWords, globalPool, rng, count = 20): QuizQuestion[]` — PURE.
  - Alternate/interleave the two kinds; target `count` questions. Each `multiple-choice` picks 1 word + 3 distractor meanings (same-level first, then global, dedup, never == correct). Each `matching` groups 4 words.
  - If level has <4 words, fall back to all multiple-choice and reduce count to what words allow (never crash). Never repeat the same word back-to-back.
- `gradeQuiz(questions, answers): { score: number; total: number; percent: number; passed: boolean }` — PURE. `answers` shape mirrors questions (string for MC, `Record<wordId,string>` for matching). A matching question scores 1 only if all 4 pairs correct (atomic) — keep simple and documented. `passed = percent >= 0.8`.
- `recordQuizResult(db, levelId, percent, today): Promise<void>` — upsert this level's `level_progress` (`onConflictDoUpdate`, set `bestQuizScore = max(excluded, existing)` via `sql`, set `completedAt = today` when `percent >= 0.8` and not already set). If passed, upsert next level (`levelId+1`) with `unlocked = 1` (only if that level exists). Mirror `practiceService.gradeCard` upsert style.

### 3. Screens
- **`src/screens/quiz/QuizHomeScreen.tsx`** — REPLACES the tab target. Update `BottomTabNavigator.tsx` Quiz tab to import from `./quiz/QuizHomeScreen` (rename export `QuizScreen`→`QuizHomeScreen`, keep old `src/screens/QuizScreen.tsx` deletable). Mirror `PracticeHomeScreen`: `useFocusEffect` reload, `import { db }`, call `getLevelProgressList(db)` from progressService. Render a list of levels: name, wordCount, best score %, and lock/complete state. Locked levels show a lock icon and are non-pressable. Unlocked → `Pressable` navigates to `QuizSession {levelId, levelName}`.
- **`src/screens/quiz/QuizSessionScreen.tsx`** — reads `route.params {levelId, levelName}`. On mount: `getQuizWords(db, levelId)`, build a seed from `levelId` + `getLocalToday()` (deterministic per day; e.g. hash string to int), `generateQuiz(...)`. ActivityIndicator while loading. Render current question (progress in header "Q n/total" via `navigation.setOptions`). MC: tap an option → record answer, advance. Matching: tap a word then a meaning to pair them; when all 4 paired, advance. Use `ArabicText` for arabic. Track answers in state. After last question → `gradeQuiz`, call `recordQuizResult(db, levelId, percent, today)`, then `navigation.replace('QuizResult', {levelId, levelName, score, total})`.
- **`src/screens/quiz/QuizResultScreen.tsx`** — reads `{levelId, levelName, score, total}`. Show percent, pass/fail (≥80%), if passed "Next level unlocked". Buttons: "Retake" → `navigation.replace('QuizSession', {levelId, levelName})`; "Done" → `navigation.navigate('Tabs')`. Dark theme, `colors.primary` accents.
